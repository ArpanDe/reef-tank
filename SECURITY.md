# Security

The screensaver itself makes no network requests and stores only its own settings on the Roku. The
development scripts talk to a Roku on your local network with the Developer Mode password you put
in `.env`, which is gitignored.

## Reporting a vulnerability

Please report security problems privately: on this repository's **Security** tab, choose
**Report a vulnerability**. Don't open a public issue for them. Reports are handled on a
best-effort basis, as this is a hobby project.

Only the latest version on the default branch is supported.
